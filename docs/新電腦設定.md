## 0. 先確認硬體：要有 NVIDIA 顯卡

語音克隆（`local_voice_batch.py`）本機 GPU 跑一筆約 **28 秒**。
沒有 NVIDIA 顯卡的話只能退回雲端 GitHub Actions，那是 CPU、**一筆 20 分鐘**且 run 有 6 小時上限——
一次上架 100 多筆會跑不完。

其餘步驟（爬蟲、上架、燒價圖）不需要 GPU，純 CPU 就能跑。

## 5. 產線怎麼跑 ＋ 重建排程

### 手動

跟 Claude Code 說「**爬蟲上架**」即可，會自動套用 `auction-publish` skill（可中途判斷與調整）。
或直接跑腳本：

```powershell
powershell -ExecutionPolicy Bypass -File run_pipeline.ps1
#   -DryRun     只跑到統計就停，不寫入任何檔案（驗證環境用）
#   -SkipCrawl  沿用 output\ 裡最新的爬蟲檔，省 25 分鐘
#   -NoPush     只 commit 不推
```

### 無人值守：重建 Windows 工作排程器

**這一項不隨 `agent:restore` 還原**，新機器要自己註冊一次：

```powershell
$script  = 'G:\我的雲端硬碟\ai agent\Queen-of-Auctions\run_pipeline.ps1'
$action  = New-ScheduledTaskAction -Execute 'powershell.exe' `
           -Argument "-NoProfile -ExecutionPolicy Bypass -File `"$script`"" `
           -WorkingDirectory (Split-Path $script)
$trigger = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Wednesday,Saturday -At '09:07'
$set     = New-ScheduledTaskSettingsSet -StartWhenAvailable `
           -ExecutionTimeLimit (New-TimeSpan -Hours 4) `
           -DontStopIfGoingOnBatteries -AllowStartIfOnBatteries -MultipleInstances IgnoreNew
$princ   = New-ScheduledTaskPrincipal -UserId "$env:USERDOMAIN\$env:USERNAME" `
           -LogonType Interactive -RunLevel Limited
Register-ScheduledTask -TaskName 'QueenOfAuctions-Publish' `
  -Action $action -Trigger $trigger -Settings $set -Principal $princ -Force
```

`-LogonType Interactive` 表示**只在你登入時執行**——語音要 GPU 與使用者 session，
本來就得登入才跑得動。`-StartWhenAvailable` 讓錯過的排程在下次開機後補跑。

確認與查歷史：

```powershell
Get-ScheduledTaskInfo -TaskName 'QueenOfAuctions-Publish' |
  Select NextRunTime, LastRunTime, LastTaskResult
```

`LastTaskResult` 就是 `run_pipeline.ps1` 的退出碼：
**0** 成功或無異動｜**1** 護欄觸發｜**2** 執行失敗｜**3** 工作區不乾淨。
詳細過程在 `output\pipeline-logs\<時間戳>.log`。

> **為什麼不用 Claude Code 的排程**：試過，2026-08-29／09-02／09-05 連續三次都在
> `git pull` 就停住——每個會寫入或連外的指令都會攔一次權限確認，排程執行時沒有人可以按。
> 這條產線不需要 LLM，改成腳本就沒有權限層，也不需要 Claude Code 開著。

## 三個最容易卡住的地方

| 卡點 | 症狀 | 解法 |
|------|------|------|
| **torch 版本錯** | `CUDA available: False`，或跑起來報 sm_120 not supported | 一定要 `--index-url https://download.pytorch.org/whl/cu128` |
| **`publish_new.py` 的 `REPO`** | 產線說「完成」但網站沒變 | 改第 36 行的絕對路徑 |
| **ffmpeg 找不到** | 語音生成到轉檔那步失敗 | 腳本用萬用字元找 `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Gyan.FFmpeg_*\ffmpeg-*-full_build\bin\ffmpeg.exe`；非 winget 安裝的要改 `local_voice_batch.py` 的 `_FF_GLOB` |
